# Pleos Connect 디자인 가이드 적용 기준 (HMTM)

출처: Pleos Connect UI Design Guide (document.pleos.ai › 앱 기획·설계 가이드 › 디자인 가이드)
- Introduction, Display Layout, Window Policy, Colors, Typography, Basic button
- 색·글자·모양 수치: Figma 리소스 Pleos_Connect_design_assets_215.fig에서 추출 (docs/pleos-tokens.json)

`docs/app-ui.md`의 화면 구성(흐름, 카드 배치, 출처 배지, 결과 화면 개편안)은 그대로 두고, 이 문서의 규칙을 그 위에 적용한다.
둘이 부딪히면 이 문서가 우선한다.

## 1. 화면 창 (가장 큰 변경)

| 가이드 | HMTM 적용 |
|---|---|
| 앱 창은 1개 또는 2개 앱을 표시. 가로 전용 게임 등을 빼면 모든 앱은 **Landscape와 Portrait 두 레이아웃**에 맞게 설계 | 모든 화면에 가로·세로 두 가지 배치를 만든다. 창 크기로 판단(WindowSizeClass 또는 가로/세로 비율), 기기 회전으로 판단하지 않는다 |
| Connect-S: 앱 2개면 1:1, 1개면 2:0 / Connect-W: 2:1 또는 1:2 | 세로 창은 폭이 좁다(가로 창의 절반 안팎). 세로 배치는 **카드를 위아래로 쌓고 한 열**로 |
| 상태 표시줄, 드라이빙 뷰, GNB는 시스템 영역. 시스템 패널·키보드가 앱 위를 잠시 가릴 수 있음 | 앱은 시스템 영역을 그리지 않는다(지금도 그렇다). 중요한 버튼을 창 맨 위·맨 아래 가장자리에만 두지 않는다 |
| 여러 차종의 해상도·비율 지원 | 고정 픽셀 금지, dp/sp와 가중치(weight) 배치 |

### 화면별 세로 배치

| 화면 | 가로 (지금) | 세로 |
|---|---|---|
| 홈 | 기록 상태 / 사고 의심 순간 2열 + 아래 큰 버튼 | 기록 상태 → 사고 의심 순간 → 큰 버튼, 한 열. 기록 항목 표는 접어서 한 줄 요약 |
| 영상 가져오기 | 단계 안내 / 선택한 영상 2열 | 단계 안내 → 선택한 영상 → 분석 시작 |
| 분석 중 | 가운데 카드 | 같음 (폭만 맞춤) |
| 질문 | 그림 / 보기 2열 | 질문 문장 → 보기(2×2 유지, 버튼 높이 유지) → 그림은 작게 또는 생략 |
| 결과 | 왼쪽(과실비율 + 입증 카드) / 오른쪽(판단 근거) | 과실비율 → 입증 카드 → 판단 근거(접힌 상태, "근거 N개 보기") |
| 기록 보기 | 그래프 / 기록 요약 2열 | 그래프 → 기록 요약 |
| 지난 분석·설정 | 목록 / 설정 2열 | 탭 2개(지난 분석 / 설정) |

## 2. 즉시성과 안전

| 가이드 | HMTM 적용 |
|---|---|
| 운전 중 시각적·인지적 부담 최소화, 1~2초 안에 파악할 핵심만 | 홈은 "기록 중" 상태 하나가 핵심. 나머지는 정차 중 화면 |
| 운전 중 동영상·움직이는 이미지·텍스트 자동 스크롤로 시선을 끌지 말 것 | 영상 다시 보기, 그래프는 정차 중에만. 진행 표시 외 애니메이션 없음. 자동으로 흐르는 글자 없음 |
| 한 손 조작, 단순한 조작만 | 끌기·두 손가락 동작 없음. 모든 조작은 한 번 탭 |
| 입력 후 0.25초 안에 응답, 늦으면 응답 중임을 표시 | 버튼에 **Loading 상태**(버튼 안 로더 + 누를 수 없음). 업로드·판정 요청·삭제 등 서버 호출 버튼 모두 |
| 터치 시 진동(햅틱) 또는 음성 피드백 | 모든 버튼·선택지에 햅틱 피드백 |

## 3. 글자 (Figma 리소스에서 확인한 값)

서체는 **Asta Sans** (Google Fonts, 한국어·영어). 크기는 가이드의 글자 스타일(Connect-S 기준, 단위 sp)을 그대로 쓴다.
Connect-W 등 다른 화면 유형 값은 `pleos-tokens.json`의 `typo_scale`에 있다.

| HMTM 용도 | Pleos 스타일 | 크기 / 줄 높이 |
|---|---|---|
| 과실비율 숫자 | Headline/Large/Strong | 60 / 80 |
| 화면 제목 | Title/Small/Strong | 32 / 40 |
| 카드 제목, 질문 문장 | Body/Large/Strong | 30 / 38 |
| 강조 본문 (선택지 버튼 글자) | Body/Medium/Strong | 28 / 36 |
| 본문 (근거 문장, 기록 요약) | Body/Small/Normal | 26 / 34 |
| 보조 (설명, 축 글자) | Label/Medium | 24 / 28 |
| 최소 (배지, 작은 표시) | Label/Small | 20 / 24 |

- 이 표 밖의 크기를 만들지 않는다. 지금 앱의 14~18sp 글자는 모두 위 단계로 올린다.
- 크기가 커지므로 한 화면에 넣던 내용이 줄어든다. 넘치는 내용은 줄이거나(문장 2줄 이내) 다음 화면·접기로 보낸다.
- 확인: 에뮬레이터에서 Pleos 기본 앱(설정 등)의 글자와 나란히 놓고 크기가 같은 단계로 보이는지 본다.

## 4. 색과 대비 (Figma 리소스에서 확인한 값)

라이트·다크 두 모드. 시스템 야간 모드를 따른다. 전체 값은 `pleos-tokens.json`의 `colors`
(값은 #RRGGBBAA 형식. Android 색으로 옮길 때 #AARRGGBB로 바꾼다).

| HMTM 용도 | Pleos 토큰 | 라이트 | 다크 |
|---|---|---|---|
| 화면 바탕 | background/primary | #F7F8FA | #1D1E21 |
| 카드 | surface/basic | #FFFFFF | #1D1E21 |
| 카드 안 강조 영역 (목록 행, 기준 상자) | surface/high | #EDEEF2 | #313236 |
| 팝업 | background/popup | #FFFFFF | #313236 |
| 본문 글자 | text/dark/primary | #131417 | #FFFFFF |
| 보조 글자 | text/dark/secondary | #131417 84% | #FFFFFF 84% |
| 덜 중요한 글자 | text/dark/tertiary | #131417 64% | #FFFFFF 64% |
| 구분선 | divider/secondary | #131417 10% | #FFFFFF 10% |
| 강조 (내 차 과실 숫자, 링크, 진행) | informative/positive | #0064FF | #0082FF |
| 켜짐·정상 (기록 중, 스위치 켬) | informative/active | #02C265 | #00E074 |
| 경고·위험 (삭제) | regulation/red | #F62E24 | #FF4339 |
| 주 버튼 바탕 | button/filled/enabled | #44464E | #E0E1E6 |
| 주 버튼 눌림 | button/filled/pressed | #313236 | #C7C9CE |
| 주 버튼 글자 | text/light/primary | #FFFFFF | #131417 |
| 보조 버튼 바탕 | button/basic/enabled | #131417 5% | #FFFFFF 5% |
| 보조 버튼 눌림 | button/basic/pressed | #131417 10% | #FFFFFF 10% |
| 비활성 버튼 | button/filled/disabled | #131417 5% | #FFFFFF 5% |
| 스위치 | switch/on, switch/off | #02C265 / #131417 30% | #00E074 / #FFFFFF 10% |

**바뀌는 점**
- **주 버튼이 파랑에서 짙은 회색(button/filled)으로** 바뀐다. Pleos 기본 UI의 버튼과 같아져서 일관성 원칙을 지킨다. 파랑(informative/positive)은 숫자 강조, 진행 표시, 링크에만 쓴다.
- "기록 중" 초록은 informative/active로.
- 삭제 버튼은 regulation/red 글자 + 보조 버튼 바탕.

**출처·효과 배지** (Pleos에 대응 토큰이 없는 HMTM 고유 요소. 기존 색을 쓰되 다크 값을 추가하고 4.5:1 검사)

| 배지 | 라이트 (바탕 / 글자) | 다크 (바탕 / 글자) |
|---|---|---|
| 차량 기록 / 차량 정보 | #E7EEFF / #1A47B8 | #1E2A4A / #A9C1FF |
| 영상 | #E4F4EA / #0B6B3A | #173226 / #8FD9AE |
| 내 답변 | surface/high / text/dark/primary | surface/high / text/dark/primary |
| 가정·추정 | #FFF1DC / #9A4A00 | #3A2A14 / #FFC27A |
| 내 과실 증가 | #FFF1DC / #9A4A00 | #3A2A14 / #FFC27A |
| 내 과실 감소 | #E4F4EA / #0B6B3A | #173226 / #8FD9AE |

- 대비: 반투명 글자(84%, 64%)는 실제 바탕과 섞은 색으로 4.5:1을 검사한다. 32%(quaternary)는 비활성 표시에만.

## 5. 버튼과 모양 (Figma 리소스에서 확인한 값, Connect-S)

| 요소 | 값 |
|---|---|
| 큰 버튼 (주 행동: 분석 시작, 결과 확정) | 높이 100, 좌우 여백 40, 최소 폭 140, 아이콘 52, 아이콘-글자 간격 16, 둥글기 32 |
| 중간 버튼 (일반) | 높이 80, 좌우 여백 32, 최소 폭 120, 아이콘 40, 간격 14, 둥글기 24 |
| 작은 버튼 (보조) | 높이 64, 좌우 여백 24, 최소 폭 100, 아이콘 32, 간격 12, 둥글기 16 |
| 아이콘 버튼 (뒤로 가기) | 80×80 (작은 것 64×64), 원형 |
| 카드·목록 둥글기 | radius level5 = 16, level4 = 12 |
| 그림자 | level1: y 6, blur 24 / level2: y 8 blur 32 + y 2 blur 2 |
| 시스템 팝업 (삭제 확인 등) | 폭 808(중간)·1200(큰), 둥글기 48, 안쪽 여백 48, 아이콘 80 |
| 토스트 | 최대 폭 792, 둥글기 16, 좌우 여백 40, 위아래 24, 아래 간격 24 |
| 화면 상단 (제목 줄) | page_navigation: 높이 80, 앞 아이콘 56, 간격 24 |

- 버튼 상태: Pressed(눌림 색) / Disabled(비활성 색, 터치 안 됨) / Loading(버튼 안 로더, 터치 안 됨). 공통 컴포넌트 하나로.
- 아이콘만 있는 버튼은 뒤로 가기만. 나머지는 아이콘 + 글자.
- 모든 버튼·선택지에 햅틱 피드백.
- 나머지 값(tabs, selections, notification 등)은 `pleos-tokens.json`의 `form_factor`.

## 6. 알림과 기타

| 가이드 | HMTM 적용 |
|---|---|
| 알림은 운전자에게 필요할 때만, 간결하게, 광고 금지 | 수집 서비스 알림은 "사고 분석용 차량 기록 중" 한 줄. 분석 완료 알림은 정차 후에만 |
| 다국어를 고려한 UI | 모든 문구를 strings 리소스로. 문구 길이가 늘어도 깨지지 않는 배치 |
| 음성 인터랙션(Gleo AI) 검토 | 보류 목록: 질문에 음성으로 답하기 |
| OTA 업데이트 고려 | 해당 없음 (앱 마켓 배포) |
